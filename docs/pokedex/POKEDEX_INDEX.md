# ポケモン図鑑 地方別インデックス

各地方のポケモン図鑑番号一覧へのリンクと概要

## 地方別図鑑一覧

### [カントー地方](POKEDEX_KANTO.md)
- 対応ゲーム：ポケモン赤・緑・青・黄・ファイアレッド・リーフグリーン・Let's Go! ピカチュウ・Let's Go! イーブイ
- 総数：151体 (No.001-151)
- 初代ポケモンが登場した最初の地方
- スターター：フシギダネ、ヒトカゲ、ゼニガメ

### [ジョウト地方](POKEDEX_JOHTO.md)
- 対応ゲーム：ポケモン金・銀・クリスタル・ハートゴールド・ソウルシルバー
- 総数：256体
- カントー地方と密接に関連した地方
- スターター：チコリータ、ヒノアラシ、ワニノコ

### [ホウエン地方](POKEDEX_HOENN.md)
- 対応ゲーム：ポケモンルビー・サファイア・エメラルド・オメガルビー・アルファサファイア
- 総数：202体（ORAS版では211体）
- 特性システムが初導入された地方
- スターター：キモリ、アチャモ、ミズゴロウ

### [シンオウ地方](POKEDEX_SINNOH.md)
- 対応ゲーム：ポケモンダイヤモンド・パール・プラチナ・ブリリアントダイヤモンド・シャイニングパール
- 総数：210体（ダイパ版151体 + プラチナ版59体）
- 物理・特殊分離が導入された地方
- スターター：ナエトル、ヒコザル、ポッチャマ

### [イッシュ地方](POKEDEX_UNOVA.md)
- 対応ゲーム：ポケモンブラック・ホワイト・ブラック2・ホワイト2
- 総数：156体（特殊な000番から開始）
- 隠れ特性システム導入
- スターター：ツタージャ、ポカブ、ミジュマル

### [カロス地方](POKEDEX_KALOS.md)
- 対応ゲーム：ポケモンX・Y
- 3つの図鑑に分類：セントラル（153体）、コースト（153体）、マウンテン（151体）
- メガシンカとフェアリータイプが初登場
- スターター：ハリマロン、フォッコ、ケロマツ

### [アローラ地方](POKEDEX_ALOLA.md)
- 対応ゲーム：ポケモンサン・ムーン・ウルトラサン・ウルトラムーン
- 総数：302体
- リージョンフォームとZワザが初登場
- スターター：モクロー、ニャビー、アシマリ

### [ガラル地方](POKEDEX_GALAR.md)
- 対応ゲーム：ポケモンソード・シールド
- 総数：400体（エキスパンションパス含む）
- ダイマックス現象が特徴
- スターター：サルノリ、ヒバニー、メッソン

### [ヒスイ地方](POKEDEX_HISUI.md)
- 対応ゲーム：ポケモンLEGENDS アルセウス
- 総数：242体
- 古代のシンオウ地方を舞台としたオープンワールド
- スターター：モクロー、ヒノアラシ、ミジュマル

### [パルデア地方](POKEDEX_PALDEA.md)
- 対応ゲーム：ポケモンスカーレット・バイオレット
- 総数：400体
- テラスタル現象が特徴の完全オープンワールド
- スターター：ニャオハ、ホゲータ、クワッス

## 図鑑番号について

- 各地方の図鑑番号は独立しており、同じポケモンでも地方によって異なる番号が割り振られています
- 全国図鑑では統一された番号が使用されますが、地方図鑑では各地方独自の順序で登録されています
- 一部の地方（カロス地方など）では複数の図鑑に分かれている場合があります

## 活用方法

- 特定の地方でのポケモンの登場順序を確認
- ゲーム攻略時の図鑑埋めの参考
- ポケモンのデザイン変遷や世代別特徴の把握
- アプリ開発における地方別フィルタリング機能の実装
