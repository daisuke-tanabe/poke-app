# ポケモン図鑑 データ

このディレクトリには、各地方のポケモン図鑑データが含まれています。

## ファイル構成

各ファイルは地方（region）ごとに整理されており、その地方に含まれるすべての図鑑データを含んでいます。

### ファイル命名規則

- `REGION_<地方名英語>.md` - 地方別の図鑑データ
  - 例: `REGION_ALOLA.md` - アローラ地方の全図鑑

### データ構造

各ファイルには以下の情報が含まれています：

1. **地方情報**
   - 地方名（日本語/英語）
   - region_id

2. **図鑑一覧**
   - 各図鑑の名前（日本語/英語）
   - pokedex_id
   - ポケモンリスト（図鑑番号順）

## データベースとの関係

- `regions`テーブル: 地方情報を管理
- `pokedexes`テーブル: 各図鑑情報を管理（region_idで地方と紐付け）
- `pokedex_entries`テーブル: 各図鑑に含まれるポケモンの番号を管理

詳細は[データベース設計書](/docs/DB_SCHEMA.md)を参照してください。
