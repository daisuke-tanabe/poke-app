# ポケモン図鑑 地方別インデックス

各地方のポケモン図鑑番号一覧へのリンクと概要

## ファイル構成について

このディレクトリには、各地方のポケモン図鑑データが含まれています。

### ファイル命名規則

- `<番号>_region-<地方名英語>.md` - 地方別の図鑑データ
  - 例: `08_region-alola.md` - アローラ地方の全図鑑

### データ構造

各ファイルには以下の情報が含まれています：

1. **地方情報**
   - 地方名（日本語/英語）
   - region_id

2. **図鑑一覧**
   - 各図鑑の名前（日本語/英語）
   - pokedex_id
   - ポケモンリスト（図鑑番号順）

### データベースとの関係

- `regions`テーブル: 地方情報を管理
- `pokedexes`テーブル: 各図鑑情報を管理（region_idで地方と紐付け）
- `pokedex_entries`テーブル: 各図鑑に含まれるポケモンの番号を管理

詳細は[データベース設計書](/docs/02_project/04_database-design.md)を参照してください。

## 図鑑番号について

- 各地方の図鑑番号は独立しており、同じポケモンでも地方によって異なる番号が割り振られています
- 全国図鑑では統一された番号が使用されますが、地方図鑑では各地方独自の順序で登録されています
- 一部の地方（カロス地方、アローラ地方、ガラル地方、パルデア地方）では複数の図鑑に分かれている場合があります

- データベース設計に基づく図鑑システムの構築
