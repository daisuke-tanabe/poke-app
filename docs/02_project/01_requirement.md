# 要件定義書

## 1. プロジェクト概要

### 1.1 プロジェクト名
ポケモン図鑑アプリ（poke-app）

### 1.2 目的
Pokemon Homeと照らし合わせてポケモンを整理しやすくするポケモン図鑑Webアプリケーションを構築する。

### 1.3 背景
- AIエージェントによる自動化・開発の限界や課題を探求し、知見を共有するためのプロジェクト
- すべてのコード・設計・データ投入はAIエージェントによる自動生成・自動化を前提とする

### 1.4 ターゲットユーザー
特定のターゲットは設定せず、一般的なポケモンファン全般を対象とする。

## 2. 機能要件

### 2.1 実装済み機能

#### 2.1.1 ポケモン一覧表示
- ポケモンの一覧をグリッド形式で表示
- レスポンシブデザインによるデバイス対応
- 図鑑番号、名前、タイプ、画像を表示
- ページネーション機能

#### 2.1.2 検索・フィルタ機能
- 地方別図鑑の切り替え
- ポケモン名での検索
- タイプによる絞り込み

#### 2.1.3 テーマ切り替え
- ライト/ダークモードの切り替え

### 2.2 直近実装予定機能

#### 2.2.1 お気に入り機能
- ポケモンのお気に入り登録
- お気に入りリストの管理

#### 2.2.2 進化系統表示
- ポケモンの進化関係を表示
- 進化条件の表示

### 2.3 中期実装予定機能

#### 2.3.1 ポケモン詳細画面
- ポケモンの詳細情報表示
- ステータス、技、特性等の情報を統合的に表示

#### 2.3.2 バトル相性計算機能
- タイプ相性の計算と表示

### 2.4 長期実装予定機能

#### 2.4.1 多言語対応
- 日本語・英語の対応

#### 2.4.2 データ更新機能
- 新世代ポケモンデータの継続的追加

## 3. 非機能要件

### 3.1 パフォーマンス要件
- 特定のパフォーマンス目標は設定しない
- Next.jsのキャッシュ機能を活用した適切な最適化

### 3.2 対応環境
#### 3.2.1 対応ブラウザ
- Google Chrome（最新版）
- Safari（最新版）
- iOS Safari（最新版）
- Android Chrome（最新版）

#### 3.2.2 対応デバイス
- デスクトップPC
- タブレット
- スマートフォン

### 3.3 アクセシビリティ
- 現時点では特定の要件なし
- 基本的なWebアクセシビリティの考慮

### 3.4 セキュリティ
- 環境変数による機密情報の管理
- Prismaによる安全なデータベースアクセス

## 4. システム構成

### 4.1 技術スタック
- **フロントエンド**: Next.js 15（TypeScript 5）
- **バックエンド**: Next.js API Routes
- **データベース**: PostgreSQL 17（Supabase CLI）
- **ORM**: Prisma 6
- **スタイリング**: Tailwind CSS
- **UIコンポーネント**: Radix UI + shadcn/ui

### 4.2 開発環境
- Node.js 22
- npm（パッケージマネージャー）
- lefthook（Git hooks）
- ESLint + Prettier（コード品質管理）
- Vitest（テストフレームワーク）

## 5. データ要件

### 5.1 データ要件
- ポケモンの基本情報（名前、タイプ、図鑑番号等）
- 地方別図鑑情報
- ポケモンの画像データ

## 6. 制約事項

### 6.1 開発方針
- AIエージェントによる自動生成・自動化を前提

### 6.2 外部連携
- 現時点でのAPI公開予定なし
- 外部サービスとの連携なし
