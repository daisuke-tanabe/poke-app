# 機能仕様書

## 1. 概要

ポケモン図鑑アプリの機能動作を定義します。技術的実装詳細は画面設計書に分離しています。

## 2. 機能仕様

### 2.1 ポケモン一覧表示機能

#### 2.1.1 基本動作
- ポケモンをグリッド形式でカード表示
- レスポンシブレイアウトでデバイスに応じた列数調整
- 1ページあたり30件の固定ページネーション

#### 2.1.2 カード表示内容
- ポケモン名（日本語）
- 図鑑番号（#付き）
- タイプアイコン（最大2つ）
- ポケモン画像（64x64px）

#### 2.1.3 フォーム切り替え機能
- **現在の動作**: 全フォームを表示
- **改修要件**: 図鑑に紐づくフォームのみ表示
  - 例：カントー図鑑のリザードン → 通常・メガX・メガY
  - 例：ブルーベリー図鑑のリザードン → 通常のみ
- 複数フォーム存在時にドットインジケーターで切り替え可能
- クリックでフォーム画像・タイプが動的変更

### 2.2 検索・フィルタ機能

#### 2.2.1 検索インターフェース
- 「Advanced Search」ボタンでモーダル表示
- 3つの検索軸を提供

#### 2.2.2 検索項目
1. **図鑑選択**
   - デフォルト：全国図鑑
   - 地方別図鑑への切り替え対応

2. **ポケモン名検索**
   - 部分一致検索
   - 日本語名・英語名両対応

3. **タイプ選択**
   - 最大2つまでの複数選択
   - チェックボックス形式

#### 2.2.3 検索実行
- 「検索」ボタンで実行
- URL更新による画面遷移
- ダイアログ自動クローズ

### 2.3 ページネーション機能

#### 2.3.1 基本動作
- 総ページ数2ページ以上で表示
- 前へ・次へボタン
- ページ番号リンク

#### 2.3.2 表示ロジック
- 5ページ以下：全ページ番号表示
- 6ページ以上：省略記号を使用した最適化表示
- 現在ページの視覚的強調

#### 2.3.3 状態保持
- 検索条件を保持したページ遷移
- URLパラメータによる状態管理

### 2.4 テーマ切り替え機能

#### 2.4.1 基本動作
- ライトモード/ダークモードの切り替え
- ヘッダー部分にトグルボタン配置

#### 2.4.2 UI表示
- ライトモード時：月アイコン表示
- ダークモード時：太陽アイコン表示
- 初期読み込み時：ローディングアイコン

## 3. データ要件

### 3.1 URL状態管理
以下のパラメータで状態を管理：
- `pokedex`: 図鑑種別（デフォルト：national）
- `page`: ページ番号（デフォルト：1）
- `name`: ポケモン名検索文字列
- `type1`, `type2`: タイプフィルタ

### 3.2 検索結果
- ポケモンリスト（30件/ページ）
- 総件数（ページネーション計算用）

## 4. ユーザーフロー

### 4.1 基本閲覧フロー
1. 初期表示（全国図鑑・1ページ目）
2. カード一覧確認
3. ページネーションで他ページ閲覧

### 4.2 検索フロー
1. Advanced Searchボタンクリック
2. 検索条件入力（図鑑・名前・タイプ）
3. 検索ボタンクリック
4. 結果表示・ダイアログクローズ
5. 必要に応じて条件変更・再検索

### 4.3 フォーム切り替えフロー
1. 複数フォーム対応ポケモンカード確認
2. ドットインジケータークリック
3. 画像・タイプの動的変更確認

## 5. 改修が必要な項目

### 5.1 フォーム切り替え機能
- **現状**: 全フォームを表示
- **改修後**: 図鑑に紐づくフォームのみ表示
- **影響範囲**: データベース設計・データ取得ロジック

### 5.2 潜在的改善項目
- ページサイズ可変対応
- 画像遅延読み込み
- 検索結果キャッシュ最適化
