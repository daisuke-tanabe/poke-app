# 実装済み機能仕様書（仮版）

## 1. 概要

現在実装されているポケモン図鑑アプリの機能を詳細に分析し、実際の動作仕様を文書化したものです。

## 2. 全体構成

### 2.1 画面構成
- メイン画面（ポケモン一覧）
- 検索ダイアログ（モーダル形式）

### 2.2 レイアウト
- レスポンシブデザイン対応
- コンテナ幅: 最大6xl（max-w-6xl）
- 左右パディング: 6（px-6）

## 3. 機能仕様

### 3.1 ポケモン一覧表示機能

#### 3.1.1 基本仕様
- **表示形式**: CSS Gridによるレスポンシブグリッド
- **レスポンシブ対応**:
  - モバイル: 2列（grid-cols-2）
  - タブレット（sm）: 3列（grid-cols-3）
  - デスクトップ（md）: 4列（grid-cols-4）
  - 大画面（lg）: 5列（grid-cols-5）
  - 超大画面（xl）: 6列（grid-cols-6）
- **1ページあたりの表示件数**: 30件（固定）
- **カード間のギャップ**: 0.5rem（gap-2）

#### 3.1.2 ポケモンカード仕様
- **カードサイズ**: 可変（親コンテナに応じて自動調整）
- **カードデザイン**: グラスモルフィズム風デザイン
  - 背景: 半透明白色（bg-white/40）
  - ボーダー: グラデーション境界線
  - バックドロップフィルター: あり（backdrop-blur-md）
  - シャドウ: なし（shadow-none）

#### 3.1.3 カード内表示項目
1. **ヘッダー部分**:
   - ポケモン名（日本語）: 左寄せ、text-sm
   - 図鑑番号: 右寄せ、#付き、text-sm、text-muted-foreground
   
2. **タイプアイコン部分**:
   - タイプアイコン表示（SVG形式、20x20px）
   - 最大2つのタイプを左寄せで横並び表示
   - パス: `/type-icons/{タイプ名}.svg`
   
3. **ポケモン画像部分**:
   - サイズ: 64x64px
   - 中央寄せ
   - Supabase Storageから取得
   - パス: `${SUPABASE_URL}/storage/v1/object/public{spriteDefault}`
   
4. **フォーム切り替え部分**（複数フォームの場合のみ表示）:
   - ドットインジケーター形式
   - 現在選択中: 青色（bg-blue-500）
   - 非選択: グレー（bg-gray-300/dark:bg-gray-600）
   - サイズ: 2.5x2.5（h-2.5 w-2.5）
   - 形状: 円形（rounded-full）

#### 3.1.4 フォーム切り替え機能
- 複数フォームを持つポケモンで利用可能
- クリックでフォーム変更
- ステート管理: useState（ローカル状態）
- アクセシビリティ: aria-label対応

### 3.2 検索・フィルタ機能

#### 3.2.1 基本仕様
- **表示形式**: Radix UIのDialogコンポーネントを使用したモーダル
- **開閉ボタン**: "Advanced Search"ボタン（右上配置）
- **ボタンスタイル**: ghost variant

#### 3.2.2 検索項目
1. **図鑑選択（PokedexSelector）**:
   - デフォルト値: 'national'（全国図鑑）
   - 地方別図鑑への切り替え対応
   - データソース: listRegionsWithPokedexes()

2. **ポケモン名検索（NameInput）**:
   - 部分一致検索対応
   - 日本語名・英語名両対応
   - URLエンコード処理あり

3. **タイプ選択（TypeSelector）**:
   - 最大2つまでのタイプ選択可能
   - データソース: listAllTypes()
   - 選択状態の視覚的表現あり

#### 3.2.3 検索実行機能
- **実行ボタン**: "検索"ボタン
- **動作**: URLパラメータ更新によるページ遷移
- **パラメータ形式**: 
  ```
  ?pokedex={slug}&page=1&name={encoded_name}&type1={type1}&type2={type2}
  ```
- **検索後**: ダイアログ自動クローズ

#### 3.2.4 URL状態管理
- **スキーマ**: Zodによるバリデーション
- **デフォルト値**:
  - pokedex: 'national'
  - page: 1
  - name: ''
  - type1, type2: ''

### 3.3 ページネーション機能

#### 3.3.1 基本仕様
- **表示条件**: 総ページ数が2ページ以上の場合のみ表示
- **コンポーネント**: shadcn/uiのPaginationコンポーネント
- **ページ計算**: Math.ceil(total / perPage)

#### 3.3.2 ページネーション表示ロジック
1. **5ページ以下の場合**: すべてのページ番号を表示
2. **6ページ以上の場合**:
   - 常に1ページ目を表示
   - 現在ページの前後1ページを表示
   - 必要に応じて省略記号（...）を表示
   - 常に最終ページを表示

#### 3.3.3 ナビゲーション要素
- **前へボタン**: 1ページ目以外で表示
- **次へボタン**: 最終ページ以外で表示
- **ページ番号リンク**: クリックで該当ページに遷移
- **現在ページ**: isActive状態で視覚的に区別

#### 3.3.4 URL生成
- 検索条件を保持したままページ遷移
- エンコード処理: encodeURIComponent使用

### 3.4 テーマ切り替え機能

#### 3.4.1 基本仕様
- **ライブラリ**: next-themes使用
- **対応テーマ**: light / dark
- **ボタン配置**: ヘッダー部分（検索ボタンの隣）

#### 3.4.2 UI仕様
- **ボタンスタイル**: ghostバリアント、アイコンサイズ、円形
- **アイコン**:
  - ライトモード時: Moon（月）アイコン
  - ダークモード時: Sun（太陽）アイコン
  - マウント前: Loader2（読み込み中）アイコン
- **アクセシビリティ**: aria-label="テーマ切り替え"

#### 3.4.3 ハイドレーション対応
- isMounted状態でSSR/CSR差異を回避
- useEffect内でマウント状態を管理

## 4. データフロー

### 4.1 データ取得
- **キャッシュ機能**: Next.js unstable_cache使用
- **キャッシュキー**: 検索パラメータ（pokedexSlug, page, pageSize, name, type1, type2）
- **リバリデーション**: 3600秒（1時間）
- **タグ**: ['pokemon-search']

### 4.2 データ変換
- **Pokemon → UIPokemon変換**: mapToUIPokemon関数
- **検索結果**: { pokemons, total }形式

### 4.3 状態管理
- **URL状態**: searchParamsによる管理
- **フォーム状態**: useReducerによるローカル状態管理
- **テーマ状態**: next-themesによるグローバル状態

## 5. パフォーマンス最適化

### 5.1 画像最適化
- **Next.js Image**: unoptimized=true設定
- **外部ストレージ**: Supabase Storage使用

### 5.2 キャッシュ戦略
- **サーバーサイドキャッシュ**: 1時間
- **クライアントサイド**: Next.jsデフォルトキャッシュ

## 6. 技術的制約・注意事項

### 6.1 既知の制約
- 1ページあたり30件固定（可変性なし）
- フォーム切り替えはクライアントサイドのみ
- 画像最適化無効化（unoptimized=true）

### 6.2 潜在的な改善点
- ページサイズの可変対応
- 画像遅延読み込み
- 検索結果のキャッシュ最適化
