# プロジェクト要件の要約

## 主要な目的
- Pokemon Homeとの照合作業を効率化するポケモン図鑑アプリ
- 横6列×縦5行の固定レイアウトで表示

## 技術スタック
- Next.js 15 + TypeScript 5
- PostgreSQL 17 (Supabase CLI)
- Prisma 6
- Tailwind CSS + Radix UI

## 実装済み機能
- ポケモン一覧表示（30件/ページ）
- 検索・フィルタ（図鑑切替、名前検索、タイプフィルタ）
- ダークモード対応

## 直近の実装予定
1. お気に入り機能
2. 進化系統表示

## 中期的な実装予定
1. ポケモン詳細画面（ステータス、技データ）
2. バトル相性計算機能

## 長期的な実装予定
1. 多言語対応（/ja、/en）
2. 新世代ポケモンの継続的追加

## 開発方針
- AIエージェントによる自動生成・自動化を前提
- 依存ライブラリのバージョン固定
